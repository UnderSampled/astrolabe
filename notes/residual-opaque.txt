# Residual opaque / not fully semantic (intentional)

Documented Type Promotion Backlog kinds now have field-level codecs in
`StructCodecRegistry` (see `notes/intermediate-type-checklist.md`). This file
lists only leftovers that are still pointer-array-only, partially opaque, or
genuinely undocumented.

## AI domain

Field-level codecs (not residual for promotion checklist):
- `script` — `ScriptBlobCodec` (forms: shell / nodes / raw). Dense ScriptNode
  params stay numeric u32 (not URI-resolved). S-expression authoring via
  `SExpressionConverter` remains optional; not required for round-trip.
- `behaviorlist_normal` / `behaviorlist_reflex` — `BehaviorListCodec`
- `behaviors_normal` / `behaviors_reflex` — `BehaviorArrayCodec` (entry fields
  + named unknowns)
- `dsgvar` / `dsgmem` — `DsgVarCodec` / `DsgMemCodec`

Still non-field-level or intentional thin:
- `scriptptrs` — `PointerArrayCodec` only (pointer table, no element schema)
- `dsgvarptrindirect` — `PointerArrayCodec` only

## Sector / collision

Promoted field-level (not residual): `sector`, `sectorname`, `sectorcollidegeo`,
`sectorcollideverts`, `collideset`, `collidezdxlist` / `collidezddlist` /
`collidezdelist`, `collidezdxzone` / `collidezddzone` / `collidezdezone`.

Still opaque / unpromoted mesh islands (not pooled as field-level structs):
- `sectorcollideelemtypes`, `sectorcollideelemptrs`
- `collideobject`, `collidevertices`, `collideelementtypes`, `collideelement`,
  `collidetriangles`
- Sector linked-list entry blobs (Env / Surf / Persos / Lights / Streams /
  *Sectors*)

Out of sector domain by design: `collidematerial` (geometry),
`persosectorinfo` (character).

## Geometry

- Undocumented mesh islands remain `types/raw/` / `RawBlobCodec`
- Fixed-struct small float fields (sphere center, material coeffs) still JSON
  scalars where promoted

## Character

- `objecttypeentry` / `objecttypename` / `alwayssuperobjects` / `dynam` are
  field-level codecs (not residual)
- `objectlistentries`: may remain `types/raw` if not registered as its own kind

## Sidecars

- RTP / RTT / RTS still heuristic uint32 scans until sidecar codec
  `PointerFields` are complete
- Full PNG corpus needs disc `Textures.cnt`; export still WireBase64 (no PNG→GF
  rebuild yet) where applicable
- Sound BNM event map incomplete (bank-level placeholders)
- Fix.ptx shared textures need Fix-package promotion pass

## Animation

Done (families + transforms dual-layer). `animhierarchies` /
`animhierarchiesheader` / `actiontable` / `actiontree` are field-level codecs.
Trailing gaps / scan-based pointer discovery on some hierarchy blobs is
preservation only, not an unpromoted kind.
